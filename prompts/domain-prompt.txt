# 도메인 정의서를 만드려면 어떤 정보를 너에게 줘야하지?
# 도메인정의서를 만들기 위한 템플릿을 md 파일로 prompts/ 디렉토리에 만들어줘

#
너는 최고의 비즈니스 도메인 전문가야. "온리원이벤트"이라는 이름의 식자재 유통 고객사 대상 이벤트 참여 애플리케이션을 만드려고 해.
다음 내용을 바탕으로 적절한 서브에이전트를 활용해 도메인 정의서 초안을 작성해줘.

# 문제 정의 :
- 식자재를 공급받는 외식업체·급식업체 등 B2B 고객사(거래처) 대상 이벤트를 진행할 별도 창구가 없어, 이벤트 등록과 참여 현황 파악이 체계적으로 이루어지지 못한다.
- 참여 방식이 단순 참여부터 추가 정보 입력, 게임형 참여까지 다양한데, 이를 한 서비스에서 유형별로 관리할 방법이 없다.
- 개인정보 사용 동의 없이 참여가 진행되는 경우 법적 리스크가 생긴다.

# 온리원이벤트 앱의 주요 기능 :
- 회원가입 + 로그인(관리자 / 일반 참여자(식자재 유통받는 고객사) 계정 분리)
- 이벤트는 참여 대상에 따라 회원 전용 / 비회원 전용 / 회원·비회원 공통 3가지 유형으로 구분됨
- 관리자는 이벤트를 등록·수정·종료할 수 있고(참여 대상 유형 지정 포함), 참여 대상(신청자) 목록을 확인할 수 있으며 개인정보 동의 보유 관련 내용 작성도 가능함
- 회원 참여자: 로그인 후 참여하며, 이미 보유한 회원 정보가 있으므로 별도 개인정보 입력 없이 개인정보 사용 동의만 하면 참여 가능
- 비회원 참여자: 로그인 없이 참여하며, 참여 시 개인정보(업체명/이름/연락처 등)를 직접 입력하고 개인정보 수집·이용 및 보유기간에 대한 동의를 해야 참여 가능
- 참여 방식은 3가지: 단순 참여(클릭형) / 추가 정보 입력형(폼 제출) / 룰렛 게임형(추첨)
- 참여하려면 개인정보 사용 동의가 필수이며(회원/비회원 공통), 동의 없이는 참여가 성립하지 않음
- 룰렛 게임형은 참여 신청과 동시에 서버가 경품 중 하나를 무작위로 즉시 확정하며, 확정된 결과는 재추첨을 허용하지 않음
- 회원 참여자는 본인이 신청한 이벤트 목록(당첨 결과 포함)을 확인하고, 필요 시 신청을 취소할 수 있음
- 회원(관리자·일반 참여자 공통)은 마이페이지에서 내 정보 조회/수정, 비밀번호 변경을 할 수 있음
- 회원 로그인 후 이용하는 기능(마이페이지 등)은 인증이 필요하지만, 비회원 전용/공통 이벤트의 참여 자체는 인증 없이 가능함
- 반응형 화면 처리가 필요한데, 관리자가 이벤트 관리나 목록 관리하는 부분은 모바일 UI에 크게 신경쓰지 않아도 됨(백오피스 항목)
- 이벤트 노출 정렬은 마감일자가 빠른 순으로 노출하는걸 우선으로 하고, 관리자가 등록했을 때 상단 노출 설정을 한건 강조표시해서 상단에 나오면 좋겠음

# 필수 사항 :
- 도메인 정의서에는 핵심적인 내용만 포함하도록 함(핵심 액터, 핵심 도메인 엔티티, 유스케이스, 예외케이스 및 비즈니스 규칙)
- MVP 범위(포함/제외)를 명시적으로 구분해서 정리함 — 특히 실제 주문/결제/정산, 재고 실시간 연동, 승인워크플로우, 포인트 적립, 검색 기능, 경품 재고 관리는 이번 개발에서는 제외함
- "참여신청"은 (이벤트, 참여자) 조합당 유일해야 하고, 취소/재신청은 새 레코드가 아니라 기존 레코드의 상태 전환으로 처리한다는 규칙을 포함함(단, 비회원은 로그인 식별자가 없으므로 이메일 또는 연락처 등 입력 정보를 기준으로 동일하게 판단함)
- 작성된 도메인 정의서를 docs/ 디렉토리에 1-domain-definition.md 파일로 저장함
