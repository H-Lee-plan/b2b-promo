# 비즈니스 관련 정보
- 목표 사용자: 식자재를 공급받는 1,000개 이상의 외식업체·급식업체 등 B2B 고객사 담당자(참여자), 이벤트를 등록·운영하는 관리자
- 비즈니스 목표: 3일 내에 이벤트 등록부터 회원/비회원 참여·룰렛 추첨까지 핵심 플로우가 동작하는 서비스를 완성하는 것이 목표이며, 3,000개 이상의 거래처 담당자가 프로모션 기능을 이용함

# 기술 제약사항
- 플랫폼 우선순위: 웹 애플리케이션, 참여자용 화면은 모바일 반응형 UI로 반드시 대응하고, 관리자 백오피스(이벤트 관리/목록 관리)는 반응형 필수 대상이 아님
                          * 반응형 웹 UI 반드시 적용
- 인프라 제약
  * 프론트엔드: React19, 전역상태관리(Zustand), TanstackQuery를 이용해 백엔드와 통신
  * 백엔드: node.js + express, pg 라이브러리
  * 데이터베이스: postgresql 17

# 프로젝트 관리
- 일정: 3일 내 핵심 기능 완성
- 팀 구성: 1인 개발
- 예산: 1인 개발에 준하는 예산

# 사용자 경험
- 사용자 페르소나: 주 사용자별 상세 시나리오는 생략
- 접근성: 이 앱에서는 고려하지 않음
- 모바일 우선: 참여자용 화면은 반응형 UI 적용(관리자 백오피스는 상황에 따라 고려하지 않아도 됨)
