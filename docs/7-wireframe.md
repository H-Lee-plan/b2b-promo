## 1. EventListPage.jsx — 이벤트 목록 (FR-1.3)

### 모바일(<768px): 세로 1열 카드 목록

```text
┌─────────────────────────────┐
│  온리원이벤트          [로그인] │  ← 헤더: 로그인 전(로그인/회원가입 링크)
└─────────────────────────────┘        or 로그인 후(사용자명 표시)
┌─────────────────────────────┐
│ ★ [상단노출] 여름맞이 룰렛대전   │  ← isPinned=true, 정렬 무관 항상 최상단
│    D-2 마감          [진행중] │
├─────────────────────────────┤
│ 신규 거래처 감사 이벤트          │  ← 이하 마감임박순(endAt asc),
│    D-5 마감          [진행중] │     동률 시 등록순(createdAt asc)
├─────────────────────────────┤
│ 봄맞이 사은품 증정              │
│    D-10 마감         [진행중] │
├─────────────────────────────┤
│ 작년 연말 이벤트                │
│    마감됨            [종료]   │  ← endAt 경과 → lazy 계산으로 종료 뱃지(S-10)
└─────────────────────────────┘
```

### 데스크톱(≥768px): 카드 그리드 배치

```text
┌──────────────────────────────────────────────────────┐
│  온리원이벤트                                  [로그인]   │
├──────────────────────────────────────────────────────┤
│ ★ [상단노출] 여름맞이 룰렛대전  │ 신규 거래처 감사 이벤트     │  ← 정렬 순서(상단노출→마감임박순)는
│    D-2 마감          [진행중] │    D-5 마감          [진행중] │     동일, 2~3열 그리드로 배치만 변경
├──────────────────────────────┼──────────────────────────┤
│ 봄맞이 사은품 증정              │ 작년 연말 이벤트             │
│    D-10 마감         [진행중] │    마감됨            [종료]  │
└──────────────────────────────────────────────────────┘
```

**반응형 전략**: 카드 내용/정렬 순서는 그대로 두고 1열→2~3열 그리드로만 reflow. 카드 자체가 곧 터치 타겟이라 열이 늘어나도 카드 높이·여백은 모바일과 동일하게 유지한다.

참고: FR-1.3 / 도메인 7절(마감임박순+동률 시 등록순+상단노출 강조 정렬) / 시나리오 S-1(1단계), S-10(자동 종료 뱃지)

## 2. EventDetailPage.jsx — 이벤트 상세 + 참여신청 (FR-1.4, FR-1.5, FR-1.6)

상태 분기 3가지: **① 회원 로그인 참여** / **② 비회원 입력 참여** / **③ 대상유형 불일치**

### ① 공통(공통 이벤트) 또는 회원 전용 이벤트 + 로그인 상태 → 회원 참여 폼

모바일(<768px): 세로 스택(정보→폼→버튼)

```text
┌─────────────────────────────┐
│ ← 목록으로        [진행중]    │
├─────────────────────────────┤
│ 여름맞이 룰렛대전               │
│ (이벤트 설명 텍스트)            │
│ 마감: 2026-08-15 23:59        │
├─────────────────────────────┤
│ 로그인 회원: 김담당 (OO식자재)   │  ← 별도 개인정보 입력 없음(도메인 7절)
│ □ 개인정보 사용 동의            │
│    (보유기간: 종료일로부터 1년)  │
├─────────────────────────────┤
│        [ 참여하기 ]           │  ← 동의 체크 전 비활성(S-2)
└─────────────────────────────┘
```

데스크톱(≥768px): 좌우 2단(왼쪽 이벤트 정보 / 오른쪽 참여 폼)

```text
┌───────────────────────────────────────────────────┐
│ ← 목록으로                              [진행중]      │
├───────────────────────┬───────────────────────────┤
│ 여름맞이 룰렛대전          │ 로그인 회원: 김담당 (OO식자재)  │
│ (이벤트 설명 텍스트)       │ □ 개인정보 사용 동의            │
│ 마감: 2026-08-15 23:59   │    (보유기간: 종료일로부터 1년)  │
│                         │        [ 참여하기 ]            │
└───────────────────────┴───────────────────────────┘
```

**반응형 전략**: 정보/폼 내용은 동일, 세로 스택→좌우 2단으로만 reflow. ②·③ 상태 및 종료/미시작 화면도 같은 2단 배치를 적용하며 별도로 반복해 그리지 않는다(내용 동일, 배치 규칙만 공유).

### ② 비회원 전용/공통 이벤트 + 비로그인 상태 → 비회원 입력 폼

```text
┌─────────────────────────────┐
│ ← 목록으로        [진행중]    │
├─────────────────────────────┤
│ 여름맞이 룰렛대전               │
│ (이벤트 설명 텍스트)            │
│ 마감: 2026-08-15 23:59        │
├─────────────────────────────┤
│ 업체명   [____________]       │
│ 담당자명 [____________]       │
│ 이메일   [____________]       │  ← 비회원 식별 기준(도메인 5·7절)
│ 연락처   [____________]       │
│ □ 개인정보 수집·이용 및         │
│   보유기간(1년) 동의            │
├─────────────────────────────┤
│        [ 참여하기 ]           │  ← 미입력/미동의 시 비활성·거부(S-2)
└─────────────────────────────┘
```

### ③ 대상유형 불일치

두 방향은 사용자 로그인 상태가 서로 반대이므로, 안내 문구만 다른 게 아니라 **화면에 노출할 액션 버튼도 달라야 한다**(비로그인 사용자에게는 로그인 유도가 유효하지만, 이미 로그인한 회원에게 "로그인/회원가입" 버튼을 다시 보여주면 무엇을 하라는 것인지 혼란을 준다).

③-1. 회원 전용 이벤트 + 비로그인(S-3 기본 케이스) → 로그인 유도 버튼 노출

```text
┌─────────────────────────────┐
│ ← 목록으로        [진행중]    │
├─────────────────────────────┤
│ 회원 전용 특별 이벤트            │
│ (이벤트 설명 텍스트)            │
│ 마감: 2026-08-20 23:59        │
├─────────────────────────────┤
│  이 이벤트는 회원 전용입니다.    │  ← TARGET_TYPE_MISMATCH 안내(S-3)
│  로그인 후 참여해 주세요.        │
│                                │
│   [ 로그인 ]   [ 회원가입 ]     │  ← 비로그인 상태에서만 의미 있는 액션
└─────────────────────────────┘
```

③-2. 비회원 전용 이벤트 + 로그인 회원(S-3 반대 케이스) → 로그인 버튼 없이 안내만 노출

```text
┌─────────────────────────────┐
│ ← 목록으로        [진행중]    │
├─────────────────────────────┤
│ 신규 거래처 감사 이벤트          │
│ (이벤트 설명 텍스트)            │
│ 마감: 2026-08-20 23:59        │
├─────────────────────────────┤
│  이 이벤트는 비회원 전용입니다.  │  ← TARGET_TYPE_MISMATCH 안내(S-3 반대 케이스)
│  회원은 참여할 수 없습니다.      │     이미 로그인한 회원이므로 로그인/회원가입
│                                │     버튼을 다시 보여주지 않는다.
└─────────────────────────────┘
```

### 참고: 종료/미시작 이벤트

```text
┌─────────────────────────────┐
│ ← 목록으로        [종료]      │
├─────────────────────────────┤
│ (이벤트 정보는 그대로 표시)      │
├─────────────────────────────┤
│   종료된 이벤트입니다.           │  ← EVENT_CLOSED, 참여 버튼 비활성(S-9, S-10)
└─────────────────────────────┘
```

참고: FR-1.4 / 도메인 6·7·8절(대상유형 검증, 동의 필수, 이벤트 상태 검증, 중복 방지) / 시나리오 S-1, S-2, S-3, S-4, S-9, S-10
