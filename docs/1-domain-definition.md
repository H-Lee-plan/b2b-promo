## 1. 개요
- 목적: 식자재 유통 B2B 고객사(거래처) 대상 이벤트를 등록하고, 회원/비회원 참여자의 신청·참여(단순 참여/폼 제출/룰렛 추첨)를 개인정보 동의 하에 체계적으로 관리한다.
- 대상 사용자:
  - 관리자: 이벤트를 등록·수정·종료하고 참여자 현황을 조회한다.
  - 회원 참여자: 로그인 후 이벤트에 참여하는 기존 거래처 담당자.
  - 비회원 참여자: 로그인 없이 개인정보를 직접 입력하고 참여하는 사용자.
- 핵심 액터
  - **관리자**: 이벤트 CRUD(등록/수정/종료), 참여 대상 유형 지정, 신청자 목록 조회, 개인정보 동의 보유 관련 내용 작성. 관리자 계정은 앱 내 회원가입으로 생성하지 않고 초기 시딩/DB 직접 등록으로 생성한다(MVP 범위).
  - **회원 참여자**: 로그인 후 참여, 본인 신청 내역/당첨 결과 조회, 신청 취소, 마이페이지(내 정보 조회·수정, 비밀번호 변경).
  - **비회원 참여자**: 로그인 없이 개인정보 직접 입력 후 참여(비회원 전용/공통 이벤트만 해당).

## 2. 용어 사전
| 용어 | 정의 |
|---|---|
| 회원 | 온리원이벤트에 가입한 계정(관리자 또는 일반 참여자로 구분). |
| 비회원 | 로그인 없이 이벤트에 참여하는 사용자로, 참여 시 입력한 개인정보로만 식별됨. |
| 참여 대상 유형 | 이벤트가 허용하는 참여자 범위. 회원 전용 / 비회원 전용 / 회원·비회원 공통 3가지. |
| 참여 방식 | 이벤트의 참여 형태. 단순 참여(클릭형) / 추가 정보 입력형(폼 제출) / 룰렛 게임형(추첨) 3가지. |
| 참여신청 | 특정 참여자가 특정 이벤트에 신청한 기록. (이벤트, 참여자) 조합당 1건만 존재. |
| 개인정보 동의 | 참여 성립의 필수 조건. 회원은 "개인정보 사용 동의", 비회원은 "개인정보 수집·이용 및 보유기간 동의"를 의미. |
| 비회원 식별 정보 | 비회원의 동일 인물 여부를 판단하는 기준. 이메일 1개로 통일한다(비회원도 이메일을 필수로 입력). |
| 경품 | 룰렛 게임형 이벤트에 관리자가 등록하는 당첨 후보 항목(꽝 포함 가능). |
| 개인정보 보유기간 | 이벤트 종료일로부터 1년. 보유기간 경과 후 파기하며, 관계 법령상 별도 보존 의무가 있는 경우 해당 기간을 우선한다. 동의 화면에 이 기간을 고지한다. |

### Enum 정의 (아래 값을 기준으로 문서 전체에서 동일하게 사용한다)
| Enum | 값 |
|---|---|
| 참여 대상 유형 (targetType) | 회원 전용 / 비회원 전용 / 공통 |
| 참여 방식 (participationType) | 단순 참여 / 폼 제출형 / 룰렛 게임형 |
| 이벤트 상태 (Event.status) | 등록 / 진행중 / 종료 |
| 참여신청 상태 (Entry.status) | 신청완료 / 취소 / 당첨 / 미당첨 (당첨·미당첨은 룰렛 게임형에서만 사용) |
| 회원 역할 (User.role) | 관리자 / 일반 참여자 |

## 3. 핵심 유스케이스
- 신규 사용자가 회원가입을 한다(회원 참여자만 해당, 관리자 계정은 회원가입 대상 아님).
- 회원(관리자/일반 참여자)이 로그인/로그아웃을 한다.
- 관리자가 이벤트를 등록/수정/종료한다(참여 대상 유형, 참여 방식, 상단 노출 여부, 룰렛 경품 목록 지정 포함).
- 관리자가 이벤트별 참여신청 목록을 조회한다.
- 관리자가 참여신청 건별로 개인정보 동의 보유 내용을 작성(기록)한다.
- 회원이 로그인 후 이벤트에 참여한다(개인정보 사용 동의만으로 참여 성립).
- 비회원이 로그인 없이 개인정보를 입력하고 동의한 후 이벤트에 참여한다.
- 참여자가 룰렛 게임형 이벤트에 참여하면 서버가 등록된 경품 목록 중 가중치 기반으로 즉시 1건을 확정한다.
- 회원이 본인의 참여신청 목록(당첨 결과 포함)을 조회하고 신청을 취소한다.
- 회원(관리자/참여자 공통)이 마이페이지에서 내 정보를 조회·수정하고 비밀번호를 변경한다.
- 이벤트 목록이 마감일자가 빠른 순으로 노출되며, 상단 노출 설정된 이벤트는 강조되어 최상단에 노출된다.

## 5. 엔티티 관계
- 회원 - 이벤트: 다대다(N:M), 참여신청을 매개로 연결.
- 이벤트 - 참여신청: 1:N (하나의 이벤트에 여러 참여신청).
- 회원 - 참여신청: 1:N (회원 참여자 기준. 비회원은 회원과 무관하게 guestEmail로 식별).
- 이벤트 - 경품: 1:N (룰렛 게임형 이벤트만 해당, 그 외 참여 방식은 경품을 갖지 않는다).
- 참여신청 - 경품: N:1 (룰렛 게임형에서 확정된 결과 참조, 그 외 참여 방식은 null).
- **(이벤트, 참여자) 조합당 참여신청은 유일하게 1건만 존재한다.** 회원은 (eventId, userId) 조합, 비회원은 (eventId, guestEmail) 조합으로 유일성을 판단한다. 취소 후 재신청은 새 레코드를 생성하지 않고 기존 참여신청 레코드의 상태를 전환하여 처리한다(단, 룰렛 게임형은 6절 규칙에 따라 취소 자체가 불가능하다).

## 6. 상태 / 라이프사이클
### 이벤트 상태
- 상태 목록: 등록 → 진행중 → 종료
- 상태 전이 규칙:
  - 등록 → 진행중: 별도 배치 스케줄러 없이, 이벤트 조회/참여 시도 시점에 현재 시각과 startAt을 비교해 즉시(lazy) 계산한다. 현재 시각이 startAt 이후이면 진행중으로 간주(또는 관리자가 즉시 시작 처리). 룰렛 게임형은 경품이 1건 이상 등록되어 있어야 진행중으로 전환할 수 있다.
  - 진행중 → 종료: 동일한 방식으로 현재 시각이 endAt 이후이면 종료로 간주, 또는 관리자가 직접 조기 종료 처리.
  - 등록 상태에서는 관리자가 모든 필드를 자유롭게 수정할 수 있다. 진행중 상태에서는 targetType(참여 대상 유형), participationType(참여 방식), startAt(시작일시)은 변경할 수 없고, title·description·isPinned·endAt(연장만 허용)은 수정할 수 있다.
- 종료/취소 조건: 종료된 이벤트는 신규 참여신청을 받지 않는다.

### 참여신청 상태
- 상태 목록: 신청완료 → (취소 | 당첨 | 미당첨)
- 상태 전이 규칙:
  - 신청완료 → 취소: 회원 참여자가 마이페이지에서 신청을 취소하면 전환. 비회원은 취소 기능 대상 아니며, **룰렛 게임형(단순 참여/폼 제출형만 대상)도 취소할 수 없다**(경품이 이미 확정·저장되었고 재추첨을 허용하지 않으므로, 취소를 허용하면 재신청 시 이전 확정 결과의 처리 방법이 불명확해지는 문제를 원천 차단).
  - 취소 → 신청완료: 취소했던 참여자가 동일 이벤트에 재신청하면, 새 레코드를 만들지 않고 기존 레코드를 신청완료 상태로 되돌린다.
  - 신청완료 → 당첨 / 미당첨: 룰렛 게임형 이벤트는 참여신청 트랜잭션 내에서 서버가 해당 이벤트의 경품(Prize) 목록을 weight 가중치 기반 확률로 추첨해 1건을 즉시 확정하고, 같은 트랜잭션에서 참여신청의 prizeId와 status(당첨: 실제 경품 당첨 / 미당첨: "미당첨" 경품 당첨)를 함께 저장한다. 이후 재추첨을 허용하지 않는다(단순 참여/폼 제출형은 당첨/미당첨 상태를 갖지 않음).
- 종료/취소 조건: 이벤트가 종료 상태이면 해당 이벤트의 참여신청은 더 이상 취소·재신청할 수 없다.

## 7. 비즈니스 규칙 및 제약조건
- 참여 성립에는 개인정보 동의가 필수이며, 동의 없이는 어떤 참여 방식이든 신청이 성립하지 않는다.
- 이벤트의 참여 대상 유형(회원 전용/비회원 전용/공통)에 맞지 않는 참여자는 신청할 수 없다.
- 회원 참여자는 별도 개인정보 입력 없이 기존 회원 정보와 "개인정보 사용 동의"만으로 참여할 수 있다.
- 비회원 참여자는 업체명/이름/연락처 등 개인정보를 직접 입력하고 "개인정보 수집·이용 및 보유기간 동의"를 해야 참여할 수 있다.
- (이벤트, 참여자) 조합당 참여신청은 유일하다. 비회원은 로그인 식별자가 없으므로 이메일을 기준으로 동일 인물 여부를 판단하여 중복 신청을 막는다.
- 취소 및 재신청은 새 참여신청 레코드를 생성하지 않고, 기존 레코드의 상태 전환으로만 처리한다. 단, 룰렛 게임형 참여신청은 취소할 수 없다.
- 개인정보는 이벤트 종료일로부터 1년간 보유 후 파기하며, 이 보유기간을 참여 시 동의 화면에 고지한다.
- 룰렛 게임형은 참여신청 시점에 서버가 해당 이벤트의 경품(Prize) 목록 중 weight 가중치 비율에 따라 1건을 즉시 확정하며, 확정된 결과는 재추첨이 불가능하다.
- 회원가입 시 email은 형식 검증 및 중복 가입을 허용하지 않고, 비밀번호(원문)는 최소 8자 이상으로 제한한 뒤 해시하여 passwordHash로 저장한다.
- 회원 로그인이 필요한 기능(마이페이지, 신청 내역 조회, 신청 취소)은 인증을 요구하지만, 비회원 전용/공통 이벤트의 참여 자체는 인증 없이 가능하다.
- 이벤트 목록은 마감일자(endAt)가 빠른 순으로 정렬하고, 마감일자가 같으면 등록일시(createdAt)가 빠른 순으로 정렬한다. 관리자가 상단 노출로 설정한 이벤트는 이 정렬과 무관하게 강조 표시되어 최상단에 노출된다.
- 관리자 백오피스(이벤트 관리/목록 관리)는 모바일 반응형 대응 대상에서 제외한다(참여자용 화면만 반응형 대응).

## 8. 예외 케이스
- 개인정보 동의를 하지 않고 참여를 시도하는 경우: 신청을 거부한다.
- 참여 대상 유형과 맞지 않는 참여자(예: 회원 전용 이벤트에 비회원)가 참여를 시도하는 경우: 신청을 거부한다.
- 이미 참여신청(신청완료 상태)이 존재하는 (이벤트, 참여자) 조합이 다시 참여를 시도하는 경우: 신규 레코드 생성 없이 중복 신청으로 처리하여 거부한다.
- 취소된 참여신청을 가진 참여자가 동일 이벤트에 재신청하는 경우: 기존 레코드를 신청완료 상태로 되돌린다.
- 비회원이 과거 입력한 이메일과 다른 이메일로 재참여를 시도해 동일 인물 판단이 불가능한 경우: 별개의 참여로 간주한다(식별 정보 불일치는 시스템이 인지할 수 없는 한계로 간주).
- 종료된 이벤트에 대한 신규 참여신청, 취소, 재신청 시도: 모두 거부한다.
- 룰렛 게임형 참여 후 결과에 불복하여 재추첨을 요청하는 경우: 이미 확정된 결과이므로 재추첨을 허용하지 않는다.
- 룰렛 게임형 참여신청에 대한 취소 시도(회원 포함): 룰렛 게임형은 취소 대상이 아니므로 거부한다.

## 9. MVP 범위
### 포함
- 회원가입/로그인(관리자·일반 참여자 계정 분리)
- 이벤트 등록/수정/종료(참여 대상 유형, 참여 방식, 상단 노출 지정)
- 참여 방식 3종(단순 참여, 폼 제출형, 룰렛 게임형)
- 회원/비회원 개인정보 동의 처리 및 참여신청(중복 방지, 취소/재신청 상태 전환)
- 관리자의 룰렛 경품 목록 등록(경품명 + 당첨 가중치)과 가중치 기반 즉시 확정(재추첨 불가)
- 회원 마이페이지(내 정보 조회/수정, 비밀번호 변경, 참여 내역/당첨 결과 조회, 신청 취소)
- 관리자 참여자(신청자) 목록 조회 및 개인정보 동의 보유 내용 작성
- 이벤트 목록 정렬(마감임박순, 동률 시 등록순 + 상단 노출 강조)
- 참여자 화면 반응형 UI (관리자 백오피스 제외)

### 제외
- 실제 주문/결제/정산 기능
- 재고 실시간 연동
- 승인 워크플로우(다단계 결재/승인)
- 포인트 적립
- 검색 기능
- 경품 재고 관리(룰렛 경품 수량 차감/소진 관리, 당첨 후 남은 수량 반영 없음)
- 앱 내 관리자 회원가입(관리자 계정은 초기 시딩/DB 직접 등록으로만 생성)
- 당첨 결과 알림 발송(이메일/SMS 등) — 결과는 참여 직후 화면 표시 및 회원 마이페이지 조회로 확인
