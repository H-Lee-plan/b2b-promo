# 프로덕션 E2E 테스트 리포트: 온리원이벤트

- 프론트엔드: `https://hyojlee-abc-fe.vercel.app`
- 백엔드: `https://hyojlee-abc-be.vercel.app`
- 테스트 방법: Playwright MCP로 실제 브라우저를 구동해 프로덕션 URL에서 `docs/4-user-scenario.md`의 S-1~S-10을 UI로 직접 재현. 서버는 별도로 띄우지 않고 실제 배포본만 사용.
- 스크린샷: `e2e/production/screenshots/`
- 테스트에 사용한 이벤트 4건, 참여신청, 회원 계정 1건은 검증 후 모두 삭제해 운영 DB를 원상 복구했습니다.

## 시나리오별 상세

### 사전 점검
- `https://hyojlee-abc-fe.vercel.app/` 접속 시 콘솔 에러 0건
- 페이지 컨텍스트에서 `fetch('https://hyojlee-abc-be.vercel.app/api/events')` 직접 호출 → `200`, CORS 정상(지난 세션에서 고친 `NODE_ENV` 무관 CORS 활성화가 실제로 반영됨)
- `/admin/login` 딥링크로 직접 접속(새로고침 없이 첫 진입) → 정상 로드(`frontend/vercel.json`의 SPA 폴백 rewrite 확인)

### S-8 (관리자 등록·운영·조기종료)
1. 관리자 로그인 화면 — 제목 줄바꿈 없이 한 줄로 정상 표시 (`s8-01-admin-login.png`)
2. 룰렛 이벤트 등록 폼 — 참여대상유형/참여방식 라디오가 텍스트와 한 줄로 정렬, 경품 3건(상품권 1/커피쿠폰 5/미당첨 94) 입력 (`s8-02-admin-event-form-roulette.png`)
3. 이벤트 4건(룰렛/회원전용/공통단순/마감경과) 등록 후 목록에서 수정·종료·삭제 버튼 크기·간격 통일 확인 (`s8-03-admin-event-list-4events.png`)
4. 참여자가 쌓인 뒤 "종료" 클릭 → 확인 다이얼로그("종료 후에는 되돌릴 수 없고, 신규 참여신청을 받지 않습니다") (`s8-04-early-close-confirm-dialog.png`) → 확정 시 즉시 종료 반영

### S-1/S-2/S-4/S-5 (비회원 룰렛)
1. 모바일 뷰(390px)에서 이벤트 목록 — 상단노출 이벤트가 파란 박스 강조로 표시(문구 없이 박스만), 대상유형 배지("공통"/"회원 전용") 정상 노출 (`s1-01-event-list-mobile.png`)
2. 비회원 입력 폼 (`s1-02-event-detail-guest-form.png`)
3. 동의 미체크 시 참여 버튼 비활성화 (`s2-01-consent-unchecked-button-disabled.png`)
4. 동의 후 참여 → 미당첨 결과 정상 표시, 재시도 버튼 없음 (`s1-03-roulette-result-lost.png`, `s5-01-result-no-retry-button.png`)
5. 동일 이메일 재참여 시도 → "이미 참여하셨습니다" 토스트, 룰렛 재동작 없음 (`s4-01-duplicate-entry-toast.png`)

### S-3 (회원 전용 + 비회원)
- 비회원이 회원 전용 이벤트 클릭 → 로그인/회원가입 유도 화면 (`s3-01-member-only-guest-blocked.png`)

### S-6 (회원가입~로그인~참여)
1. 회원가입 → 오답 비밀번호 로그인 시도 시 "이메일 또는 비밀번호가 일치하지 않습니다" (`s6-01-login-wrong-password.png`)
2. 정상 로그인 후 회원 전용 이벤트 참여(개인정보 입력 없이 동의만) → "참여가 완료되었습니다" (`s6-02-member-participation-complete.png`)

### S-7 (취소 불가/취소·재신청)
1. 회원이 룰렛(당첨/커피쿠폰) + 단순참여 2건 보유 → 마이페이지에서 룰렛 건에는 취소 버튼 없음 (`s7-01-mypage-entries-roulette-no-cancel.png`)
2. 룰렛 참여신청 취소를 서버 API로 직접 호출해도 `400 VALIDATION_ERROR`("룰렛 게임형 참여신청은 취소할 수 없습니다.")로 거부 확인
3. 단순참여 취소 → "취소" 상태 반영 (`s7-02-mypage-after-cancel.png`)
4. 재참여 → 새 레코드 없이 "신청완료"로 복귀 (`s7-03-mypage-after-reapply.png`)

### S-9 (종료 후 신규 참여 차단)
1. 참여신청 목록에서 비회원 1건(미당첨) + 회원 1건(당첨/커피쿠폰) 총 2건 정상 표시 (`s9-01-admin-entries-list-2.png`)
2. 참여자 화면에서도 "종료된 이벤트입니다" (`s9-02-participant-closed-event-detail.png`)
3. 종료 후 참여 API 직접 호출 시 `409 EVENT_CLOSED` 확인

### S-10 (마감 경과 자동 종료)
- 관리자가 "종료" 버튼을 누른 적 없는 이벤트(마감일만 경과)도 목록·상세에서 "종료"로 lazy 계산되어 표시 (`s10-01-event-list-closed-badge.png`, `s10-02-lazy-closed-event-detail.png`)

## 발견 사항

버그 없음. 이전 로컬 E2E(`e2e/report.md`)에서 발견했던 두 버그(미당첨 경품명 하드코딩, lazy 종료 이벤트 연장 불가) 중 첫 번째는 이번에도 정확한 이름("미당첨")으로 등록해 정상 동작을 재확인했고, 두 번째(연장 불가)는 이번 스위트 범위에 포함하지 않았습니다. 이전 세션에서 고친 UI 이슈(라디오 정렬, 버튼 스타일, 상단노출 박스 강조, 대상유형 배지, CORS, SPA 폴백)는 모두 프로덕션에서 의도대로 동작함을 확인했습니다.
